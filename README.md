## Geometrie-Aufgaben und Puzzles

Übungsnotebooks zur Geometrie: Jede Aufgabe besteht aus einer Aufgabenstellung
(Markdown-Zelle) und einer Lösung in Python (Code-Zelle mit ausgeführtem Ergebnis).

Benutzt wird nur die Standardbibliothek (`math`, `itertools`, `collections`,
`functools`) – es sind also keine Zusatzpakete nötig, das läuft auch auf dem iPad.
Die Zellen bauen innerhalb eines Notebooks aufeinander auf, am besten von oben
nach unten ausführen.

| Notebook | Inhalt |
| --- | --- |
| `003_geometrie_grundlagen.ipynb` | Ebene Figuren: Pythagoras, Heron, Kreis / Ring / Sektor, Vielecke, Flächenformeln |
| `004_geometrie_koerper.ipynb` | Körper: Quader, Zylinder, Kegel, Kugel, Pyramide, kleinste Oberfläche |
| `005_geometrie_koordinaten.ipynb` | Koordinatensystem: Abstand, Geraden, Schnittpunkte, Schnürsenkelformel, Punkt im Polygon, Dreieckszentren |
| `006_geometrie_puzzles.ipynb` | Puzzles: Quadrate im Schachbrett, Satz von Pick, pythagoreische Tripel, Dreiecksungleichung, verstümmeltes Schachbrett, Gitterwege |

Am Ende jedes Notebooks stehen unter „Übung für dich" bzw. „Und jetzt du"
weitere Aufgaben – diesmal ohne Lösung.
